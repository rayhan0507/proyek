FOLDER SYNC TOOL - LEVEL 1

Tujuan:
Copy file dari source ke target jika file belum ada di target.

Kondisi awal:
source/ -> a.txt, b.txt, c.txt
target/ -> a.txt

Tugas:
1. Gunakan pathlib untuk membaca isi source.
2. Cek apakah setiap file sudah ada di target.
3. Jika belum ada, copy dengan shutil.copy2().
4. Target akhirnya harus punya a.txt, b.txt, c.txt.

Contoh output:
File sudah ada: a.txt
Copy: b.txt
Copy: c.txt

Tools yang disarankan:
- pathlib.Path
- Path.iterdir()
- Path.exists()
- shutil.copy2()
